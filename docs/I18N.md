# Internationalization

Angie Scientific supports French and Spanish through i18next.

## Languages

- French: default and fallback language.
- Spanish: supported language.

## Resources

Translation namespaces live under:

```text
src/locales/fr/
src/locales/es/
```

Current namespaces:

- `common`
- `navigation`
- `auth`
- `settings`
- `periodicTable`
- `quantum`
- `fusion`

## Runtime Behavior

`src/i18n.ts` initializes i18next with browser language detection. The detector
checks local storage and the browser language. Language changes update
`document.documentElement.lang`.

`src/hooks/useLanguage.ts` exposes:

- `language`
- `setLanguage`
- `t`

## Contribution Checklist

- Add new user-facing keys to both `fr` and `es`.
- Keep namespace names consistent.
- Avoid hard-coded UI strings in components when the text is user-facing.
- Verify the affected view in both languages when practical.
